System Design

End-to-End Modular Architecture

How VisionEye transforms high-definition video into real-time spatial intelligence across 5 interconnected architectural tiers.

T1

1. Ingestion & Input Streams

Ingests 30–60 FPS video streams from USB/FaceTime HD webcams, industrial RTSP surveillance streams, and looping local MP4/MOV files with automated reconnection and zero memory fragmentation.

T2

2. Edge CV & Neural Pipeline

Applies 640×640 letterbox scaling, ultra-fast YOLO26n ONNX neural inference (9–12ms), ByteTrack Kalman state tracking, virtual counting line vector debouncing, 4-point homography 2D ground projection, and privacy blurring.

T3

3. Daphne ASGI & Telemetry Server

Django 5 Channels backend powered by Daphne ASGI. Broadcasts low-latency telemetry updates via WebSockets (/ws/analytics/), serves high-speed MJPEG video feeds (/api/video/feed), and exposes REST endpoints.

T4

4. Universal Client Layer

Cross-platform Electron 30 desktop builds for macOS (Apple Silicon & Intel), Windows, and Linux alongside a responsive React 18 / Vite SPA for instant browser access on smartphones, tablets, and PCs.

T5

5. CI/CD & Cloud Infrastructure

Automated GitHub Actions CI gatekeeper (13/13 Pytest test suite), multi-platform Docker container deployment to production VM via Nginx reverse proxy with TLS/SSL, and automatic binary releases.

Core Capabilities

Engineered for Real-Time Edge Intelligence

Zero external cloud dependencies. Everything runs locally on your workstation or embedded terminal.

YOLO26n ONNX Neural Engine

Ultra-lightweight person detection model (10.7MB, ~2.4M parameters) delivering 9ms inference latency with Apple Silicon CoreML hardware acceleration.

ByteTrack Multi-Person Tracking

Industrial Kalman filtering with Hungarian IoU association maintains persistent track IDs across dense pedestrian crowds and brief occlusions.

4-Point Homography Top-View Minimap

Transform angled surveillance camera footage into a 2D bird's-eye orthographic ground plane with 1-click auto-calibration and real-time perspective mapping.

Virtual Counting Line & Analytics

Sub-pixel line-crossing detection with directional enter/exit debouncing, real-time venue occupancy tracking, and timeline flow history.

Privacy Protection Masking

On-the-fly anonymization applying dynamic Gaussian blur or pixelation filters over detected human bounding boxes prior to stream encoding.

Multiple Input Feeds

Supports dynamic macOS / USB webcams, MP4/MOV video files (with continuous seamless looping), IP RTSP surveillance cameras, and synthetic generators.

Quick Start & Setup

Step-by-Step Installation Guide

Follow these simple steps to install and run VisionEye on your computer or test instantly in your browser.

  • 1

    Download the DMG installer for your Mac

    Choose VisionEye-macOS-AppleSilicon.dmg if you have an Apple Silicon Mac (M1, M2, M3, M4) or VisionEye-macOS-Intel.dmg for Intel-based Macs.

  • 2

    Open DMG & Drag into Applications

    Double-click the downloaded .dmg file. In the window that opens, drag the VisionEye icon and drop it into your Applications folder.

  • 3

    Launch the Application

    Open VisionEye from your Applications folder, Spotlight Search (Cmd + Space), or Launchpad.

    💡 First Launch Tip (macOS Gatekeeper): If you see "VisionEye cannot be opened because it is from an unidentified developer":
    1. Open Finder ➔ Go to Applications.
    2. Right-click (or Control-click) on VisionEye and select Open.
    3. Click Open in the confirmation prompt. (You only need to do this once).
  • 4

    Allow Camera Permission & Start Tracking

    When prompted, click Allow to grant camera access for your webcam, or upload any MP4 video file to start real-time foot-traffic counting immediately!

  • 1

    Download the Windows Installer

    Download VisionEye-Windows-x64.exe from the download section above.

  • 2

    Run the Installer (.exe)

    Double-click VisionEye-Windows-x64.exe to begin the setup wizard.

    💡 Windows SmartScreen Tip: If you see a blue window saying "Windows protected your PC":
    1. Click the text link: "More info".
    2. Click the button: "Run anyway".
  • 3

    Choose Installation Location & Shortcuts

    Choose whether to create a Desktop shortcut and Start Menu entry, then click Install. All dependencies and AI models are self-contained — no Python or Node.js required!

  • 4

    Launch & Start Analyzing

    Launch VisionEye from your Desktop or Start Menu. Connect your USB/integrated webcam or upload surveillance video clips to view real-time occupancy and IN/OUT counts.

  • 1

    Download the Portable AppImage

    Download VisionEye-Linux-x64.AppImage (or the .deb package for Ubuntu/Debian).

  • 2

    Make the File Executable

    Right-click the downloaded file ➔ Properties ➔ Permissions ➔ Check "Allow executing file as program", OR run in your terminal:

    chmod +x VisionEye-Linux-x64.AppImage
  • 3

    Launch Application

    Double-click the AppImage or execute from your terminal:

    ./VisionEye-Linux-x64.AppImage
  • 1

    Instant Access on Any Mobile Device

    No app store downloads or APK installations needed! VisionEye runs natively inside Google Chrome, Safari, Firefox, Edge, and Samsung Internet on Android smartphones, iPhones, iPads, and Android tablets.

  • 2

    Launch the Live Application

    Tap the launch button below to open the real-time AI foot-traffic analytics dashboard directly on your device:

    ⚡ Launch Live Web App
  • 3

    (Optional) Add to Your Mobile Home Screen (PWA)

    You can turn VisionEye into a full-screen standalone app icon on your phone:

    🤖 On Android (Chrome): Tap the 3 dots menu (⋮) at top right ➔ Tap "Add to Home screen" or "Install app".
    🍏 On iPhone/iPad (Safari): Tap the Share button (⎋ with arrow) at bottom ➔ Tap "Add to Home Screen".
